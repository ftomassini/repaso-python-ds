# Repaso de Python para Data Science

Práctica de repaso de los fundamentos de Python, previa al trabajo con librerías de análisis de datos.

## Contenido

- `analisis_basico.py` — script con las cuatro tareas resueltas.

## Temas que cubre

1. **Definición de variables** — uso de los tipos básicos (`str`, `float`, `int`, `bool`) e impresión con f-strings.
2. **Lógica de negocio** — recorrido de una lista con un bucle `for` y clasificación de cada precio como "Caro" o "Económico" mediante un condicional `if / else`.
3. **Estructura de datos compleja** — diccionario `almacen` que relaciona cada producto con su stock, con alta de un producto nuevo y consulta de un valor puntual.
4. **Modularización con funciones** — función `resumen_estadistico(numeros)` que recibe una lista y devuelve un diccionario con la suma total, el promedio y la cantidad de elementos.

## Cómo ejecutarlo

```bash
python3 analisis_basico.py
```

No requiere dependencias externas: sólo la librería estándar de Python 3.
